# העלאה לסטייג׳

בפאנל הקומיט יש שלוש רשימות: **בהתנגשות**, **לא בסטייג׳** ו**בסטייג׳**. כל אחת
מתכווצת, וכל אחת זוכרת אם השארתם אותה פתוחה.

![דיף שאינו בסטייג׳, עם פקדי הקטע והקובץ לצדו](../../screenshots/line-staging.webp)

## שלוש רמות של דיוק

| רמה | איך |
|---|---|
| **קובץ** | לחצו על ה־✚ שבשורה, או בחרו כמה שורות והעלו את כולן בבת אחת |
| **קטע** | פתחו את הדיף והשתמשו בכפתור שבכותרת הקטע |
| **שורה** | רחפו מעל שורה שהשתנתה בדיף ולחצו על ה-**+** שלה, או סמנו כמה שורות והעלו אותן |

העלאת שורות היא מה שהופך לפרקטי להשאיר `console.log` של ניפוי באגים מחוץ לקומיט
בלי למחוק אותו קודם.

## העלאת שורות בודדות לסטייג׳

פתחו את הדיף של קובץ שלא בסטייג׳, בתצוגה המאוחדת או המפוצלת. רחפו מעל שורה
שנוספה או נמחקה, ובתחילתה יופיע **+** ירוק קטן: לחיצה אחת מעלה לסטייג׳ את
השורה הזו ותו לא. שאר הקטע נשאר מחוץ לסטייג׳ — בדיוק כאילו ערכתם את הקטע ביד
ב-`git add -p`.

לכמה שורות בבת אחת, לחצו על השורות עצמן כדי לסמן אותן — <kbd>⇧</kbd>-לחיצה
לוקחת כל שורה שהשתנתה מהשורה האחרונה שלחצתם — ולחצו **העלאת N שורות לסטייג׳**
בסרגל שמעל הדיף.

זה עובד גם בכיוון ההפוך. פתחו את הגרסה **שבסטייג׳** של קובץ, והפקדים הופכים ל-**−**
אדום, **הורדת הקטע מהסטייג׳** ו-**הורדת N שורות מהסטייג׳**: הם מוציאים שורות
מהאינדקס ולא נוגעים בעץ העבודה.

הסירו את השינוי האחרון מהצד שאתם צופים בו, והדיף יעבור אחרי הקובץ לצד השני
במקום להישאר ריק.

כל שורה או קטע שהעליתם או הורדתם כך אפשר לבטל עם **ביטול** בסרגל הכלים, לחיצה
אחת בכל פעם.

| מה שבחרתם | העלאה לסטייג׳ | הורדה מהסטייג׳ |
|---|---|---|
| שורה שנוספה | השורה נכנסת לאינדקס | השורה יוצאת מהאינדקס |
| שורה שנמחקה | השורה יוצאת מהאינדקס | השורה חוזרת לאינדקס |
| אף אחת, באותו קטע | נשארת כמו שהיא, רק בעץ העבודה | נשארת בסטייג׳ |

### מגבלות

- **רווחים מוסתרים, אין סטייג׳.** כל עוד *רווחים לבנים* מתעלמים, הדיף משמיט
  שינויים ולא יכול לומר אילו שורות להעלות; הפקדים מוסתרים עד שתכבו זאת.
- **קבצים לא במעקב** עולים בשלמותם. העלו קודם את הקובץ, ואז הורידו את השורות
  שאינכם רוצים.
- **השורה האחרונה בקובץ בלי ירידת שורה בסופו** עלולה להידחות אם תפרידו את
  השינוי שלה משורות שנוספו אחריה — git לא יודע לתאר את מצב הביניים הזה כטלאי.
  העלו אותן יחד.
- **ביטול דורש את האינדקס כפי שהשארתם אותו.** אם מאז העליתם עוד מאותן שורות,
  git מסרב לבטל במקום לנחש, ואומר זאת.

## זריקה

זריקה עובדת באותן רמות, ותמיד שואלת. קבצים שאינם במעקב נמחקים; קבצים במעקב
חוזרים למצב שבו הם נמצאים בסטייג׳ (או בקומיט).

## מקלדת

<kbd>↑</kbd> <kbd>↓</kbd> (או <kbd>j</kbd> <kbd>k</kbd>) מהלכים על רשימות
הקבצים, עם <kbd>⇧</kbd> לטווח ועם <kbd>⌘</kbd>/<kbd>Ctrl</kbd> כדי לסמן ולבטל
קבצים בודדים.

<kbd>⇧</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> מרחיבים את הבחירה מהשורה האחרונה שלחצתם
עליה. לחיצה ימנית על הבחירה מאפשרת להוסיף לסטייג׳, להסיר ממנו, להכניס לסטאש או
לזרוק את הכול בבת אחת.

## העתקת נתיבים

לחיצה ימנית על קובץ שעוד לא נכנס לקומיט מציעה **העתקת נתיב הקובץ** (מוחלט,
עם מפרידי הפלטפורמה) ו**העתקת נתיב קובץ יחסי** (`src/index.ts`, בלי `./`
בהתחלה). כמה קבצים שנבחרו מעתיקים נתיב אחד בכל שורה, לפי סדר הרשימה. קבצים
שנמחקו נשארים זמינים — הפעולות האלה מעתיקות רק טקסט. תיקיות ממשיכות להעתיק
את נתיב התיקייה.

## לפני שאתם מבצעים קומיט

Gitcito בודק כמה דברים ושואל פעם אחת, אף פעם לא בשקט:

- קובץ שנראה כמו **סוד** (`.env`, `*.pem`, `id_rsa`…),
- בלוב **גדול במיוחד** (הסף בהגדרות ← אבטחה),
- קומיט **ישירות לענף מוגן** (`main`/`master` כברירת מחדל).

כל אחד מאלה מציע *החרגה והסרה מהמעקב* בלחיצה אחת. ראו
[אבטחה וסודות](security.md).
