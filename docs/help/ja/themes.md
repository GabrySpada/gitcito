# テーマと外観

組み込みテーマ — Gitcito、Nord、Dracula、Solarized、GitHub、Kraken、Monokai、
Midnight、Contrast、Daltonic — それぞれにライトとダークの2種類があります。

![ライトからダークへの切り替え](../../screenshots/clip-themes.webp)

![Kraken テーマ](../../screenshots/theme-kraken.webp)

**Kraken** を選ぶと、グラフもそのレーン配色と **淡色** の参照ラベル——各レーンの色を
沈めた暗いプレート、GitKraken と同じ描き方——に切り替わります。切り替わるのは選んだ
ときの一度だけです。あとから 設定 → テーマ → **グラフ**（*参照ラベル*: 塗りつぶし／
淡色）で変えれば、その設定が保たれます。
さらにレーンを **列ごと** に色分けします（*レーンの色*）。同じレーンを通るブランチは、
それぞれ別の色ではなく、ひとつの色を共有します。

Kraken は色だけでなく書体も変えます。Nunito の代わりに Open Sans、より太い
文字、明るいバー上の等幅の列見出し、大きめの ref ラベルとサイドバーの見出し、
明るいツールバー。このスタイルはテーマそのものに属するため、Kraken から
コピーしたカスタムテーマは色だけを引き継ぎます。
選択時にはコードの配色も Kraken（GitKraken の差分が使う VS Code の Dark+）
に、コードのフォントも 12px に、グラフ設定と同じく一度だけ切り替わります。

- **ライト、ダーク、または OS に追従**。切り替えは即座に反映されます。
- **カスタムテーマ**、そしてプロンプトから作る **AI 生成** テーマ。
- 調整可能な **コードの文字サイズ**。
- 独立した **グラフのスタイル**: レーンのパレット、角の形、行の密度、線の太さ。
  ミニグラフのプレビューがその場で追従します。

![テーマの設定](../../screenshots/settings-themes.webp)

## レイアウト

サイドバーは左にも右にも置けます。パネルはどこでもサイズを変えられ、グラフに
ウィンドウ全体を使わせたいときのために折りたためるサイドバーがあり、ターミナルの
配置はリポジトリごとに決められます。
