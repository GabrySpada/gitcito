# 暂存

提交面板有三个列表：**有冲突**、**未暂存**和**已暂存**。每个都能折叠，而且每个都会记住你把它留在了展开还是收起的状态。

![一处未暂存的差异，旁边是变更块与文件的操作按钮](../../screenshots/line-staging.webp)

## 三个精度层级

| 层级 | 怎么做 |
|---|---|
| **文件** | 点击该行上的 ✚，或者选中若干行一次性全部暂存 |
| **变更块** | 展开差异，用变更块标题栏上的按钮 |
| **行** | 在差异里把鼠标移到改动行上并点击它的 **+**，或选中若干行后暂存这些行 |

正是有了逐行暂存，才让「把一句调试用的 `console.log` 挡在提交之外、又不必先把它删掉」变成一件可行的事。

## 暂存单独一行

打开一个未暂存文件的差异，统一视图或分栏视图都可以。把鼠标移到新增或删除的行
上，行首会出现一个绿色的小 **+**：点一下，就只暂存这一行，别的都不动。这一块
的其余部分仍未暂存——和在 `git add -p` 里手工编辑这一块的结果完全一样。

要一次处理多行，直接点击这些行把它们选中（<kbd>⇧</kbd>-点击会选中从上次点击
的行起所有改动行），然后按差异上方栏里的 **暂存 N 行**。

反过来也行。打开文件 **已暂存** 的版本，控件会变成红色的 **−**、**取消暂存这
一块** 和 **取消暂存 N 行**：它们把行从索引里拿出来，不碰工作区。

当你正在查看的这一侧最后一处改动被移走，差异不会变成空白，而是跟着文件切换到
另一侧。

用这种方式暂存或取消暂存的每一行、每一块，都可以用工具栏的 **撤销** 一次一步
地撤回。

| 你选的 | 暂存它 | 取消暂存它 |
|---|---|---|
| 新增的行 | 索引里多出这一行 | 索引里少了这一行 |
| 删除的行 | 索引里少了这一行 | 这一行回到索引 |
| 两者都不是（同一块内） | 保持原样，只留在工作区 | 仍然是已暂存 |

### 限制

- **隐藏空白时不能暂存。** 忽略 *空白字符* 时，差异会略去一些改动，无法判断
  该暂存哪些行；在你关掉它之前，控件会隐藏。
- **未跟踪的文件** 只能整个暂存。先暂存整个文件，再取消暂存不想要的行。
- **结尾没有换行符的文件的最后一行**，如果把它的改动和其后新增的行拆开，可能
  会被拒绝——git 无法把这种半截状态写成补丁。把它们一起暂存。
- **撤销要求索引保持你离开时的样子。** 如果之后你又暂存了同样几行里的更多内
  容，git 会拒绝撤销而不是去猜，并会说明原因。

## 丢弃

丢弃在同样这三个层级上都能用，而且每次都会先问你。未跟踪的文件会被删除；已跟踪的文件则回到它已暂存（或已提交）的状态。

## 键盘

<kbd>↑</kbd> <kbd>↓</kbd>（或 <kbd>j</kbd> <kbd>k</kbd>）在文件列表里上下移动，按住 <kbd>⇧</kbd> 可以选一段范围，<kbd>⌘</kbd>/<kbd>Ctrl</kbd> 则用来单独切换某个文件的选中状态。

<kbd>⇧</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd>
从最后点击的那行开始扩展选择。在选中项上右键，可以一次把它们全部暂存、取消暂存、贮藏或丢弃。

## 复制路径

在未提交的文件上右键，可以 **复制文件路径**（绝对路径，使用当前平台的分隔符）
和 **复制相对文件路径**（`src/index.ts`，不以 `./` 开头）。多选时每行一条，
顺序与列表一致。已删除的文件仍然可用——这两项只复制路径文本。文件夹仍复制
文件夹路径。

## 提交之前

Gitcito 会检查几件事，并且只问你一次，绝不悄悄放行：

- 看起来像**机密**的文件（`.env`、`*.pem`、`id_rsa`…），
- **超大**的二进制对象（阈值在 设置 → 安全 中），
- **直接提交到受保护的分支**（默认是 `main`/`master`）。

以上每一项都提供一键的*忽略并取消跟踪*。参见[安全与机密](security.md)。
