# Port brief (condensed copy of the owner's session brief)

This is the approved design for porting Gitcito from Electron to **Wails v3**. Every subagent reads it.
Where it conflicts with `CLAUDE.md`, this brief wins. Decisions taken during the port live in
`docs/port/DECISIONS.md`.

## 0. Decisions already made — do not revisit

| # | Decision | Consequence |
|---|----------|-------------|
| D1 | Full Go rewrite of the main process. | Every module in `src/main/` becomes Go. No Node.js at runtime. No sidecar. git stays a **CLI subprocess** (`os/exec`) — never go-git. |
| D2 | Replace Electron, full parity. | When parity is proven, delete Electron, electron-vite, electron-builder, electron-updater, `@electron/rebuild`, `src/preload`, `src/main`, `test/stubs/electron.ts`. |
| D3 | Fresh start for user data. | New data dir and keychain service; **never read** `<UserConfigDir>/Gitcito`. No migration. Version **5.0.0**. |
| D4 | The app may run headless. | Wails **server build** driven by Playwright, and short native smoke launches that are always killed. Every launch uses a throwaway `GITCITO_DATA_DIR`. |
| D5 | Push the branch + open a draft PR. | Never merge, never push to `main`, never tag/release, never force-push. |
| D6 | DevTools panel → system browser. | The `<webview>` DevTools page is removed; the launch toolbar's DevTools button opens the loopback URL with `Browser.OpenURL`, still gated by `isLoopbackUrl`. |
| D7 | Subagents run on Opus. | |
| D8 | Wake build system, CGO on. | `wails.yaml`, `WAILS_EXP_USE_WAKE=1`. No purego. |

## 1. Wails v3 facts

- Pinned: **Wails v3.1.0** (`wails3` CLI, `go.mod`, `@wailsio/runtime` exact). Go toolchain via
  `toolchain go1.26.10` in `go.mod`. Run Go commands with `GOTOOLCHAIN=go1.26.10` if the system go is older.
- The `wails3` CLI is at `~/go/bin/wails3`. Every `wails3` command needs `WAILS_EXP_USE_WAKE=1`.
- Wails docs (Markdown) and source: a clone of `wailsapp/wails@v3.1.0` lives at
  `/tmp/claude-0/-home-user-gitcito/256a45eb-4382-5e8b-99ba-b0398e16d0a8/scratchpad/ext/wails`
  (`docs/mpress/content/...`, Go source under `v3/pkg/application`, `v3/pkg/updater`). The Go source is the
  final authority on API names. A generated reference project lives next to it in `.../scratchpad/ref`.
- Linux targets GTK4 + WebKitGTK 6.0 (installed in this container).
- **Known limitations to design around:**
  1. Every exported method on a registered service is callable from the page. Services are thin facades;
     anything that must not be callable from JS is unexported or in an unregistered package.
  2. Child frames can reach bound methods. Never embed untrusted content in a same-origin frame.
  3. A dialog requested before `app.Run()` does nothing.
  4. Concurrent event emits have no defined order. Use a stream where order matters.

## 2. What must not be lost

Read the comments in the TS source: many lines exist because of a bug someone already hit. In particular:
- `noPromptEnv()` and why git runs through `execFile` (PAGER, GIT_ASKPASS, exit-code semantics of
  `merge-base --is-ancestor` and `config --get`).
- `fixPath()`: GUI launches inherit a minimal PATH; the login-shell PATH is restored before any spawn.
- The per-repo read/write lock: **the first argument is the repo path and the lock key**, and an
  unclassified method is a **write**.
- `run()` / `refetch` identity semantics in `stores/repo.ts`, undo entries, toast/busy labels from the dictionary.
- The `--shot` store bridge and `GITCITO_SSH_DIR` (honoured **only** under `--shot`).
- `gitcito --wait <file>` editor flow: git blocks on a sentinel, every path out releases it exactly once.
- Error markers parsed by the renderer (`FILE_TOO_LARGE_PREFIX` in `src/shared/types.ts`, every
  `*_PREFIX`/marker constant). Go error strings stay **byte-identical**.

## 4. Contract capture (M0)

- `docs/port/INVENTORY.md`, generated by `scripts/port/inventory.mjs`: one row per IPC channel, event and
  gitService method (kind, args, return type, events, source file:line, renderer call sites, Go owner, status, test).
- Goldens from the TS implementation, replayed forever by Go tests:
  1. Git READ methods → `internal/gitsvc/testdata/goldens/<method>/<fixture>-<case>.json` (paths normalized to
     `<REPO>`/`<HOME>`/`<TMP>`).
  2. Git WRITE methods on `cloneFixture()` copies → resulting repo state snapshot + return value.
  3. Shared pure logic used by main → `testdata/vectors/<module>.json`, run by **both** vitest and Go.
  4. Crypto/file formats (secure bundles v1/v2, wikiPack, vault/settings) → vectors Go must decrypt and
     re-encrypt byte-for-byte; plus a TS-opens-Go-bundle round trip before TS is deleted.
  5. Model-facing payloads (AI request bodies) and hosting API requests (minus auth) from fixed inputs.
  6. CLI: stdout, stderr, exit code of every `gitcito` CLI verb.

### 5.2 The bridge keeps `window.api`'s shape

- `PreloadApi` moves to `src/shared/bridgeApi.ts` as an explicit type.
- `src/renderer/src/infrastructure/bridge.ts` implements it on top of the generated bindings and
  `@wailsio/runtime`; it is the **only** renderer file importing `@wailsio/runtime` or `./bindings`.
- `main.tsx` awaits `bootstrap()` (one bound call → `{ platform, shotMode, version, … }`), installs the bridge as
  `window.api`, then renders.
- **Error contract:** a Go error rejects the promise; the bridge normalizes it to `Error(message = Go error
  string)`. Panics are recovered into errors.
- **Serialization contract (JSON, not structured clone):**
  - nil slices → return `[]`, never `null`, wherever TS expects an array.
  - optional fields (`?:` in TS) → `omitempty`/pointers so absent stays `undefined`.
  - `[]byte` travels as base64; the bridge encodes/decodes.
  - JSON tags match TS property names exactly.

### 5.3 Electron → Wails mapping (abridged)

| Electron | Wails |
|----------|-------|
| `ipcMain.handle` | exported method on a registered service |
| `ipcRenderer.send` | bound method the bridge does not await |
| `webContents.send` | `app.Event.Emit(name, data)`; channel names identical |
| `term:data:<id>`, `launch:data:<id>`, `localci:data`, `bisect:output`, `clone:progress` | ordered streams or events; order matters |
| the `'git'` dispatcher | one typed method per gitService method on `GitService`, wrapped by the per-repo RW lock; a Go test asserts every exported method is classified read or write in an explicit table |
| `dialog.*` | `app.Dialog` builders; never before `Run` |
| `shell.openExternal` | `app.Browser.OpenURL` with the `^https?://` check in Go |
| `safeStorage` | `internal/keychain`: random 32-byte master key in the OS keychain (`github.com/zalando/go-keyring`), secrets files AES-256-GCM; same consent flow; service `com.gitcito.desktop` / `.dev` |
| `app.getPath('userData')` | `<os.UserConfigDir()>/com.gitcito.desktop` (prod) / `com.gitcito.desktop.dev` (dev); `GITCITO_DATA_DIR` override; file names stay `gitcito-*.json` |
| single instance | `SingleInstanceOptions` with a per-user encryption key from a 0600 file |
| `node-pty` | `github.com/aymanbagabas/go-pty` (creack/pty + ConPTY) |
| `child_process` | `os/exec` with `context.Context`, process-group kill, explicit env, output size limit |
| `fs.watch` watcher | `github.com/fsnotify/fsnotify`, same debounce / mute / light-heavy classification |
| semantic diff (`semantic.ts`) | moves to the renderer (`src/renderer/src/lib/semantic.ts`), stays TypeScript |

### 5.5 Go style

- `gofmt`, `go vet`, staticcheck clean. Comments explain **why**; port the TS why-comments with the logic.
- `context.Context` first on anything that spawns or does I/O. Wrap errors with `%w`. No panics across the bridge.
  No package-level mutable state without a mutex.
- Services are thin facades over internal packages. Each service file starts with a comment listing the
  renderer channels it serves.
- No `any` at the bridge where a struct can be declared; `json.RawMessage` only where TS is `unknown`.

## 7. Testing

- `internal/testutil`: `Playground(t)` runs `examples/setup-playground.sh` once per process;
  `CloneFixture(t, name)` copies into `t.TempDir()`. **Never mutate a shared playground repo.**
- Every package replays its goldens/vectors. Table-driven tests. `httptest.Server` fakes for hosting/AI; no live network.
- `-race` for gitsvc (lock), terminal, watcher, launch.
- `docs/port/TEST-MAP.md` maps **every** existing vitest case to its new home. Final count (Go + vitest) ≥ 1686.

## 8. Security

- `docs/port/SURFACE.md`: every exported service method (the attack surface).
- No method returns a raw token/secret unless today's channel did; no arbitrary path without today's validation
  (`isSafeRepoPath` for model/CLI paths). Tokens never logged.
- CSP kept, minimally extended. Iframes `sandbox` without `allow-same-origin`. Repo content through DOMPurify.
- Navigation lock; `OpenURL` http(s)-only. Single-instance messages encrypted. Updater fails closed (ed25519).
- Destructive operations keep their confirms. No new network endpoints, no listening ports, no telemetry.
- git argument injection: `--` separators, refuse refs starting with `-` where today does.

## Hard rules

- Never touch the owner's real app data, keychain, `~/.ssh` or global git config: tests use temp dirs.
- Every user-facing string goes through the i18n dictionaries, in **every** locale file.
- Kill every process you start. Never report green over red.
- Subagents: do not ask questions — decide, and list decisions in your report. Do not commit unless told to.
